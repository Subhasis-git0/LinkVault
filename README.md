LinkVault 

Your personal, cloud-powered bookmark manager.

LinkVault is a Flutter Web application that helps you save, organize, search, and manage useful links in one place. With Firebase Authentication and Cloud Firestore, your bookmarks, notes, and categories are stored in the cloud and scoped to your account.

🌐 Live Demo: [linkvault-9cd9c.web.app](https://linkvault-9cd9c.web.app)

Version: `1.0.0`

Features

- User Authentication — Sign up and log in using Firebase Authentication.
- Bookmark Management — Add, edit, and delete saved links.
- Personal Notes — Attach notes to bookmarks.
- Categories — Organize bookmarks using multiple categories and custom categories.
- Search and Filtering — Find bookmarks using the available search and category filters.
- Cloud Persistence — Store bookmarks and categories in Cloud Firestore.
- User-Scoped Data — Firestore security rules restrict access to each user's data.
- Dark UI — A dark-themed dashboard built with Flutter.
